In some recent commits we settled on a policy for when the app is used in
landscape vs portrait orientation. It is the home route that is used by the user
the vast majority of the time, and that route is designed specifically for a
landscape orientation. On mobile, we encoure the user to switch to landscape on
the home route - with an in-page message in the letterbox free space to tell them
the "The diagram will be bigger...". The next most used route is for the user to
set or change their own location. This UI is infeasible at mobile sizes on
landscape, so in this case we tell them they HAVE to switch to portrait to change
the location. I very much like the end result of these decisions, but it leaves
us with one main problem when the user chooses to install the app using PWA. We
encourage that.
