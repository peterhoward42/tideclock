5. Edge cases to design for explicitly
Missing expiry in JSON: fallback TTL, or always refetch, or fail closed — but don’t silently use only maxAgeMs without documenting it as fallback.
Clock skew: expiresAt in the past immediately after fetch → treat as stale or clamp; optional small skew buffer if the API contract allows.
Serialization: version the storage key or record shape if you add expiresAt so old localStorage entries don’t parse as valid forever.
