# Framing for PWA

See docs/specs/elevator-pitch.md for context.

The app already supports PWA capability and this is not about changing that. Instead it is about how we frame and present the "offer" to the site visitor in the menu.

I would like the entry point menu item which is currently "Install App" to be "Install as Always-On Display". Possibly accompanied by a subtext saying "Designed to be left running on a kitchen tablet or wall-mounted screen".

I'm not completely happy with how the menu currently expands to give more details at the moment. I see there being two roles for that. One is to present the value proposition. And the other is to explain how to do it. It already does that. But I'm neither quite happy with the current proposition copy, nor that it expands in situ in the menu. I'm wondering if a new route might provide a better intermediary step.
